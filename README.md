# MOLLI

초파리 후각 회로를 그대로 본뜬 강화학습 에이전트와, 그 에이전트가 실제로 게임을 하는 실험실.

```
후각엽(PN) → 버섯체 케니언세포(KC, 희소코딩) → 도파민(DAN) 보상신호 → 출력뉴런(MBON)
```

같은 뇌 하나로 세 가지를 시킵니다.

| 탭 | 무엇을 | 브릿지 필요? |
|---|---|---|
| 향기 추적 | 10×10 격자에서 냄새 기울기를 따라 보석 찾기 | 아니오 |
| 지뢰찾기 | 9×9 / 지뢰 10개. 제약 전파로 뽑은 특징을 학습 | 아니오 |
| 뱀서 (화면 조작) | 화면을 공유받아 진짜 뱀파이어 서바이버즈를 플레이 | **예** |

`data/drosophila_neurons/` 에는 NeuroMorpho.org에서 받은 실제 초파리 뉴런 형태 데이터
107개가 들어 있습니다 (구조 설계의 근거 자료).

## 한 방에 띄우기

```powershell
.\start.ps1
```

이것만 하면 됩니다. 도커로 게임 페이지를 올리고, 도커에 담을 수 없는 브릿지만 그 창에서 띄웁니다.

```powershell
.\start.ps1 -Live    # 실제로 키를 누른다 (기본은 안전모드)
.\stop.ps1           # 도커 내리기. 브릿지는 Ctrl+C
```

게임 페이지는 <http://localhost:8743>. `restart: unless-stopped` 라서 재부팅해도 알아서 다시 뜹니다.
**향기 추적과 지뢰찾기는 브릿지 없이 그냥 됩니다** — 브라우저만 열면 됩니다.

## 왜 브릿지만 도커 밖인가

```
게임 화면 ──화면공유──▶ 브라우저 (인식 + 판단) ──WebSocket──▶ bridge.py ──키입력──▶ 게임
   [호스트]                    [호스트 브라우저]                  [호스트]        [호스트]
                                     ▲
                                     │ 페이지 서빙
                              nginx 컨테이너 :8743
                                                            Ollama (네이티브 또는 컨테이너) :11434
```

브라우저는 화면을 보고 판단할 수는 있지만 **보안 샌드박스 때문에 다른 프로그램에 키를 보낼 수 없습니다.**
그 마지막 한 칸이 브릿지인데, 컨테이너 안에서는 이것도 불가능합니다. 윈도우는 세션이 격리돼 있어
다른 세션의 창에 입력을 넣지 못하기 때문입니다. 그래서 브릿지만 호스트에 남습니다.

나머지 — 페이지 서빙과 LLM — 은 전부 컨테이너로 갑니다.

## Ollama

레벨업 카드 선택과 화면 판별에 씁니다. 브릿지는 **주소만** 보므로 네이티브든 도커든 상관없습니다.

```powershell
docker compose --profile ollama up -d   # 도커 Ollama 띄우기
.\import-models.ps1                     # 모델을 볼륨으로 복사
```

`--profile ollama` 로 띄우면 볼륨이 비어 있어서 페이지에 **"모델 없음"** 이 뜹니다.
네이티브에 받아둔 모델은 저장 위치가 달라서 따라오지 않기 때문입니다.
`ollama pull` 로 7.6GB를 다시 받을 필요는 없습니다 — `import-models.ps1` 이
`C:\Users\<이름>\.ollama\models` 를 볼륨으로 그대로 복사합니다. 로컬 복사라 금방입니다.

포트는 하나뿐이라 **네이티브와 도커가 동시에 11434를 쓸 수 없습니다.** 먼저 뜬 쪽이 잡습니다.
어느 쪽이 답하고 있는지는 `.\start.ps1` 이 2단계에서 알려줍니다.

다른 PC에 있을 때는 주소만 바꿉니다. 소스는 건드릴 것이 없습니다.

```powershell
bot\.venv\Scripts\python.exe bot\bridge.py --ollama http://192.168.0.50:11434
```

모델 선택 근거와 실측치는 [bot/README.md](bot/README.md) 에 있습니다.

## 안전장치

키 입력은 되돌릴 수 없으므로 겹겹이 막아뒀습니다. 자세한 내용은 [bot/README.md](bot/README.md).

- **기본이 안전모드** — `-Live` 없이는 키를 누르지 않습니다
- **키 화이트리스트** — WASD/방향키/엔터/스페이스만. **ESC는 어떤 경우에도 나가지 않습니다**
  (한때 봇이 ESC를 눌러 게임을 꺼버린 적이 있어서, 탐색 자체를 없앴습니다)
- **워치독** — 0.5초 동안 명령이 끊기면 눌린 키를 전부 놓습니다
- **마우스 안 씀** — 모니터가 여러 대면 좌표가 주 모니터로 튑니다. 키보드만 씁니다

## 폴더

```
game/                브라우저에서 도는 전부 (뇌, 환경, 렌더링, 3D 몰리)
  agent.js           PN → KC → MBON 학습 규칙. 세 탭이 같이 씁니다
  env.js             향기 추적 환경
  minesweeper.js     지뢰찾기 환경 + 특징 추출
  vampire.js         화면 인식 · 판단 · 화면 판별 · LLM 연동
  molli.js           저폴리 3D 마스코트 렌더러 (외부 라이브러리 없음)
bot/bridge.py        브라우저의 판단을 실제 키 입력으로 옮기는 로컬 브릿지
data/                초파리 뉴런 형태 데이터 (SWC)
```
